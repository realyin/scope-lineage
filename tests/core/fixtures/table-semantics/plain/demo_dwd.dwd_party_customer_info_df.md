## 一页纸

**这张表是什么**：客户主表：每个客户号一行，取核心系统客户注册记录里最后更新的一条。

**一行是什么**：一个客户（按客户号）在某一天的最新注册信息。粒度按 `customer_id`，来源为已证明，全表唯一。同一个 dt 分区内按客户号唯一；每天各有一份全量。

**更新与取数**：每天跑一次，每个分区是一份**全量快照**。取某一天的客户用 dt = 那一天；每个分区是当天的全量，不要把多个 dt 分区相加。

**收哪些数据**：

- 只看核心系统客户注册表当天分区里的记录。（规则 r1）
- 同一个客户号有多条注册记录时，只保留最后更新的一条。（规则 r2、r3）

**数据从哪来**：

| 上游表 | 在本表的作用 |
| --- | --- |
| `demo_ods.ods_core_customer_df`（主表） | 全部业务字段：客户号、实名客户号、性别、注册时间、实名状态；更新时间用来挑最新一条。 |

**谁在用**：下游任务 `dwd_lending_borrower_daily`（写 `demo_dwd.dwd_lending_borrower_df`）、`dws_lending_loan_summary_daily`（写 `demo_dws.dws_lending_loan_summary_1d`）。

**适合用来**：按客户号查某一天客户的最新注册信息；按性别、实名状态统计某一天的客户数
**不适合**：看客户注册信息的变更历史：每天只留最新一条，改动之前的值不在这张表里

**要注意**：

- 注册时间由秒级时间戳转换而来，按集群默认时区解释。（风险）

## 加工过程

**产出任务**：`dwd_party_customer_info_daily`（每天）：每天从核心系统客户注册表里为每个客户号保留最新一条注册记录，作为下游借款人和贷款汇总使用的客户主表。

1. 取核心系统客户注册表当天分区的记录。
2. 按客户号分组、按更新时间倒序编号，每个客户号只留编号为 1 的一条。
3. 转换注册时间、加上装载时间，写入当天分区。

## 规则（原文）

| 规则 | 业务说法 | SQL 原文 |
| --- | --- | --- |
| r1 过滤 | 只取注册表当天分区 | `WHERE dt = '${bizdate}'` |
| r2 去重 | 每个客户号按更新时间倒序编号 | `ROW_NUMBER() OVER (PARTITION BY cust_no ORDER BY update_ts DESC)` |
| r3 过滤 | 只保留编号为 1 的最新一条 | `WHERE rn = 1` |
